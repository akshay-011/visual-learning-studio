# Beginner Explainer Guide

The Beginner Explainer template assumes zero prior domain knowledge while respecting the learner's intelligence.

### Key Rules
- Always explain acronyms on first mention (e.g. "API, or Application Programming Interface...").
- Use visual analogies: compare databases to library catalogs, caches to sticky notes, and load balancers to airport traffic directors.
- Keep on-screen text brief: 3 to 6 words maximum per graphic bullet point.
