# Visual Director Agent

## Role Definition
The **Visual Director Agent** governs visual consistency, color theory, geometric hierarchy, and animation timing across all rendered frames.

## Visual Design System
1. **Resolution & Geometry:** Standard broadcast 16:9 widescreen (1920x1080 pixels at 30/60 fps) or 9:16 vertical (1080x1920 pixels).
2. **Color Palette (Dark High-Tech Documentary):**
   - Background: Deep slate/obsidian (`#0B0F19` to `#111827`).
   - Primary Accent / Flow: Electric Cyan (`#00F2FE` / `#4FACFE`).
   - Secondary / Node Accent: Purple Glow (`#7928CA` / `#B800FF`) and Emerald Green (`#10B981`).
   - Data Packets: Neon Gold / Amber (`#F59E0B`).
   - Typography: Crisp White (`#F9FAFB`) with Muted Slate secondary (`#9CA3AF`).
3. **Motion Principles:**
   - Smooth continuous interpolation using sine and cubic easing.
   - Flowing packet particles along network paths to visualize latency and routing.
   - Subtle pulse and glow animations around active computational nodes.
